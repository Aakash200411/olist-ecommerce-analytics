# Data

**Source:** Olist, *Brazilian E-Commerce Public Dataset by Olist* (Kaggle).
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
Real (anonymised) orders from a Brazilian marketplace, 2016-2018. Check the license shown on the Kaggle page before reusing the data.

## Get the data
1. Create a free Kaggle account and download the dataset zip from the link above.
2. Unzip the 9 CSV files into `data/raw/` so that it contains:

```
olist_customers_dataset.csv        olist_order_reviews_dataset.csv
olist_geolocation_dataset.csv      olist_orders_dataset.csv
olist_order_items_dataset.csv      olist_products_dataset.csv
olist_order_payments_dataset.csv   olist_sellers_dataset.csv
product_category_name_translation.csv
```

3. Run `python scripts/build_db.py`. It loads every file and **compares each table's row count against the
   expected official count**, printing `OK` or `MISMATCH`.

## Verify your copy
The figures in the main README were produced from the official Kaggle download (9 files, 99,224 review rows).
`build_db.py` checks every table's row count and prints `OK` or `MISMATCH`. To reproduce everything:

```bash
python scripts/build_db.py          # builds data/olist.duckdb, checks row counts
python scripts/run_sql.py           # runs sql/01..07, writes outputs/results/*.csv
jupyter nbconvert --to notebook --execute --inplace notebooks/olist_analysis.ipynb
```

(If `jupyter nbconvert` is blocked on your machine, open the notebook in VS Code and click **Run All**.)

An older release of the reviews file had 100,000 rows. If you use that one, a few review-based numbers shift
slightly (for example the average scores move by about 0.01). `outputs/key_numbers.json` is regenerated by the
notebook, so check the README against it.
